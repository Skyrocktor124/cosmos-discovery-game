## 六、执行顺序

1. 生成 A1 画风参考图并确认。第一眼必须有明显的"不会画"和"简笔画"感；若只是漂亮的商业插画叠加纸纹与粉彩滤镜，判为风格失败并重新生成。
2. 生成 A2–A8 共 7 张人物与道具参考图并逐张确认。缺任何一张不得进入第 4 步。
3. 建立参考资产记录：稳定标识、类型、用途、完整生成提示词、来源画布与节点、本地下载路径、确认状态。
4. **只生成片段 1**，不接音频参考。检查旁白完整性、音色、音量、语速、实际画幅与片尾噪音。
5. 通过 LibTV CLI 下载片段 1，用 FFmpeg 转为 **48kHz、双声道、16-bit PCM WAV**（Linux 与 Windows 均用 FFmpeg，macOS 可用 `afconvert`），再通过 LibTV CLI 上传为独立音频节点。**不要用 M4A**，该格式曾被 Seedance 拒绝。
6. 片段 2–8 各自连接：该纯音频作为 `音频1`，加 A1，加本段所需人物与道具参考图。核对素材顺序、Prompt 与参数后并行提交。
7. 逐片质检，只把通过的片段按顺序拼接。

## 七、质检要点

按这支片子的实际风险排序：

- **画风漂移**是最大风险。官方指南专门列出该问题：参考图风格不够极端时，输出容易滑向写实或精致插画。每段抽查开头、中段、结尾的实际帧，一旦出现干净流畅的线条、完整背景或三维光影，判失败并重新生成。
- **人物套脸**。片段 3 同时出现弗朗索瓦一世与达芬奇，是最容易互相串脸的一段，重点核对。
- **蒙娜丽莎画作跨片段一致性**。片段 3 与片段 7 中画框与画中人姿态必须完全一致。
- **群演画风统一**。片段 1、5、8 大量使用无身份参考的背景人物，必须与主要人物属于同一造型和渲染体系，不得出现写实或另一套卡通风格。
- **画幅**。不能只读 `ratio`、分辨率或容器元数据，必须查看开头、中段、结尾的实际画面有无上下或左右黑边。若出现，在重生成 Prompt 中加入正向构图要求"所有镜头采用满幅画面，场景与背景完整覆盖整个可见构图区域"，不要改写成技术参数。
- **片尾噪音**。带旁白的片段片尾容易出现截断咔哒声，拼接前对每段片尾做音量淡出处理。
- **中文发音**。"腓力二世"的"腓"、"贝聿铭"的"聿"属于模型容易读错的字。片段 2 与片段 8 若出现读音错误，按官方建议替换为发音一致的常用同音字后重新生成。
- **拼接跳变**。若改用视频延长方式衔接，在拼接点将前一段末尾删 6 帧、后一段开头删 1 帧。本方案采用分段生成后拼接，不使用视频延长。
